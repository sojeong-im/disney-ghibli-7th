# 🎞️ 디즈니와 지브리의 행방불명 7기 지원서 웹 폼

대학생 연합 영화·애니 친목동아리 **「디즈니와 지브리의 행방불명」** 7기 신규 크루 모집을 위한 반응형 웹 어플리케이션입니다.

- 🌐 **배포 사이트 URL**: [https://disney-ghibli.netlify.app](https://disney-ghibli.netlify.app)
- 🔥 **Firebase Project**: `disney-ghibli` (Firestore `applications` 컬렉션 실시간 연동)
- 🐙 **GitHub 저장소**: [https://github.com/sojeong-im/disney-ghibli-7th](https://github.com/sojeong-im/disney-ghibli-7th)
- ⚙️ **Netlify 대시보드**: [https://app.netlify.com/projects/disney-ghibli](https://app.netlify.com/projects/disney-ghibli)

## 📌 7기 추가 모집 요강

- **🏰 디즈니조**: 추가 모집 8명
- **🌿 지브리조**: 추가 모집 12명
- **모집 기간**: 10월 26일 ~ 11월 26일
- **활동 기간**: 약 3~6개월
- **활동 주기**: 격주 1회 정기 활동 (자율 참여)

---

## 🎨 주요 특징 & UI/UX

1. **상세 페이지 배제 & 첫 화면 즉시 몰입형 히어로 UI**:
   - 감성적인 포스터 비주얼과 조별 모집 현황(디즈니조 8명, 지브리조 12명)을 한눈에 파악
   - **📸 활동사진 보기**: 정기 영화상영회, 전시회 & 투어, 피크닉 번개 모임 갤러리 모달
   - **✨ 7기 지원서 작성하기**: 클릭 즉시 1문항씩 부드럽게 넘어가는 카드형 지원서 시작
   - **동아리 소개 팝업**: 동아리 소개 및 지원 전 확인사항(활동 기간, 자율 참여, 클린 수칙 등) 확인 가능

2. **10가지 공식 지원 문항 완벽 반영 (스텝 바이 스텝)**:
   - **Q1. 이름**: 실명(본명) 입력 (단답형, 필수)
   - **Q2. 나이와 성별**: 예: 23세 / 여성 (단답형, 필수)
   - **Q3. 대학교 / 학과 / 학년**: 휴학/졸업/취준생 가이드 포함 (단답형, 필수)
   - **Q4. 연락처 & 인스타그램 ID**: 2칸 분리 인풋으로 가독성 및 정확도 극대화 (필수)
   - **Q5. 최애 영화/애니와 그 이유**: 지브리/디즈니 대표작 원클릭 빠른 입력 칩 + 장문 텍스트 (필수)
   - **Q6. 희망 조 선택**: 🏰 디즈니조 / 🌿 지브리조 / 💫 둘 다 좋아요! 배정에 맡길게요 (객관식 1개, 필수)
   - **Q7. 희망 활동**: 빔프로젝터 감상, 신작 영화관 관람, 카페 방문, 전시/팝업, 최애작 소개, 친목 + **기타 직접 입력** (체크박스 복수 선택, 필수)
   - **Q8. 활동 참여 가능 정도**: 정기+번개 적극참여 / 정기 위주 / 자율 참여 (객관식 1개, 필수)
   - **Q9. 지원 이유와 기대하는 점**: (장문형, 필수)
   - **Q10. 자기소개**: 성격, 취미, 친해지는 스타일 등 (장문형, 선택)

3. **지브리 감성 피드백 & 티켓 발권**:
   - Web Audio API 기반 소프트 차임 사운드 효과 (ON/OFF 지원)
   - 상단 진행률 프로그레스 바 & `Enter` 키 원터치 이동
   - 작성 완료 시 축하 폭죽(Confetti) 및 **7기 크루 탑승권(Boarding Pass)** 티켓 발권
   - 공유하기 & 링크 복사 기능

4. **운영진 전용 관리자 기능 (Admin)**:
   - 메인 화면 하단 **운영진 접수 목록** 클릭 시 전체 지원자 목록 및 답변 열람
   - **CSV (엑셀) 다운로드** 기능 내장으로 한 번에 스프레드시트 정리 가능
